同步HDLC帧涉及对连续数据比特流进行解码，以查找指示帧（数据包）开始和结束的比特模式。出现连续的6个1（即01111110）时，即表示帧边界的“标志”。为避免数据流意外包含“标志”，发送方在每5个连续的1之后插入一个0，接收方必须检测并丢弃该0。我们还需要在出现7个或更多连续1时，发出错误信号。创建一个摩尔型有限状态机来识别以下三种序列：

  (1) 0111110：发出需要丢弃一个比特的信号（disc）。
  (2) 01111110：标记帧的开始/结束（flag）。
  (3) 01111111...：错误（7个或更多1）（err）。

当有限状态机复位时，它应处于一个行为类似于前一个输入为0的状态。复位信号为高电平有效的同步信号。输出信号应从条件发生后的下一个时钟周期开始持续整个周期。假设所有时序逻辑都在时钟的上升沿触发。

### 主动信号：
- `clk` : 时钟信号，用于同步状态转移和输出。
- `rst` : 复位信号，同步高有效，复位后状态机处于初始状态（假设之前输入为0）。
- `bit_in` : 输入比特流，用于检测序列。

### 从动信号：
- `disc` : 输出信号，当检测到状态机state为S5状态，即检测到5个连续1后跟0（序列0111110）时，在下一个周期输出1个周期的高电平信号。
- `flag` : 输出信号，当检测到状态机state为S6状态，即检测到6个连续1后跟0（序列01111110）时，在下一个周期输出1个周期的高电平信号。
- `err` :  输出信号，当检测到状态机state为S7状态，当检测到7个或更多连续1时，从下一个周期开始输出高电平，并持续每个周期直到输入变为0（即连续1序列结束）。

### 内部寄存器信号：无

### 内部关键标志信号：无

### 内部状态机：
- `state` : 用于记录输入序列的进展，moore型，无编码方式要求。
状态定义：
  - `S0` : 初始状态，表示之前输入为0或没有连续1。
  - `S1` : 收到1个连续1。
  - `S2` : 收到2个连续1。
  - `S3` : 收到3个连续1。
  - `S4` : 收到4个连续1。
  - `S5` : 收到5个连续1。
  - `S6` : 收到6个连续1。
  - `S7` : 收到7个或更多连续1（错误状态）。
  - `S_disc` : 输出`disc`的状态，持续一个周期。
  - `S_flag` : 输出`flag`的状态，持续一个周期。
转换条件：
- 复位时，状态为`S0`。
- 从`S0`：`bit_in=0`保持`S0`，`bit_in=1`转移到`S1`。
- 从`S1`：`bit_in=0`转移到`S0`，`bit_in=1`转移到`S2`。
- 从`S2`：`bit_in=0`转移到`S0`，`bit_in=1`转移到`S3`。
- 从`S3`：`bit_in=0`转移到`S0`，`bit_in=1`转移到`S4`。
- 从`S4`：`bit_in=0`转移到`S0`，`bit_in=1`转移到`S5`。
- 从`S5`：`bit_in=0`转移到`S_disc`，`bit_in=1`转移到`S6`。
- 从`S6`：`bit_in=0`转移到`S_flag`，`bit_in=1`转移到`S7`。
- 从`S7`：`bit_in=0`转移到`S0`，`bit_in=1`保持`S7`。
- 从`S_disc`：无论`bit_in`如何，转移到`S0`。
- 从`S_flag`：无论`bit_in`如何，转移到`S0`。
